# Sample Data

Bu klasor ornek DICOM dosyalari icin ayrilmistir.

Gercek hasta verisi kullanirken hasta gizliligine dikkat edin. Proje arayuzde hasta adini veya kisisel bilgileri gostermez; yine de DICOM dosyalarini paylasmadan once anonimlestirmek en dogru yaklasimdir.

Kendi DICOM serinizi bu klasore koyabilir veya Streamlit arayuzunde baska bir klasor yolu verebilirsiniz.
